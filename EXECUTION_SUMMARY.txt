================================================================================
CLASS IMBALANCE HANDLING STRATEGIES IMPLEMENTED
================================================================================

1. SMOTE (Synthetic Minority Over-sampling Technique)
   - Generates synthetic samples for the minority class
   - Reduces bias toward majority class
   - Applied during training only (not on test data)
   - Results in balanced training distribution

2. Class Weights (Inverse Frequency Weighting)
   - Penalizes misclassification of minority class more heavily
   - Integrated into RMS-HL loss function
   - Applied in SVM models via class_weight='balanced'
   - Enables models to focus on underrepresented samples

3. Appropriate Evaluation Metrics
   - F1 Score: Harmonic mean of precision and recall
   - ROC-AUC: Threshold-independent discrimination measure
   - Balanced Accuracy: Class-independent accuracy measure
   - Recall & Precision: Individual class performance indicators
